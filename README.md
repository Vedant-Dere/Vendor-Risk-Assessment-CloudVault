# Third-Party Vendor Risk Assessment (TPRM)

**Role:** Lead GRC Analyst
**Target Vendor:** CloudVault Inc. (SaaS Provider)

## Project Overview
This repository contains a comprehensive Third-Party Risk Assessment of a prospective SaaS vendor handling internal PII. The assessment framework aligns with SOC 2 and ISO 27001 standards.

### Current Deliverables:
* **Vendor Gap Analysis:** Identification of critical control exceptions across Identity Management, Cryptography, Disaster Recovery, and Incident Response.
* *(Coming Soon)* **Risk Register:** Quantitative scoring of identified vulnerabilities.
* *(Coming Soon)* **Executive Risk Memo:** Final board-level recommendation (Accept/Mitigate/Reject).
